## Upstream changes

- The TUI defaults to an owned fullscreen transcript and local daemon startup.
  `/tui` selects the next launch's mode. Native terminal scrollback remains an
  alternative rather than the fullscreen transcript's scrolling mechanism.
- Unicode equation layout, Mermaid rendering, table improvements, and
  `tui.rendering` preferences extend Markdown rendering.
- Agent control moves behind a runtime interface. Message-board support,
  lifecycle changes, and conditional interruption improve agent coordination.
- Model catalogs gain GPT-6 Sol/Luna entries, Bedrock support, and additional
  role, tool-description, and parameter-schema overrides.
- Workspace routing discovers the selected account's backend and routing header.
  Guardian thread context is enabled by default; configurable extra policy and
  policy templates are added.
- State migrations 56 and 57 add creator identity and normalize synthetic
  Guardian metadata. Thread-history migration 7 adds item lifecycle timestamps.
  Rust 1.95.0 and V8 150.4.0 remain pinned.

## Custom-feature integration

- The configured base prompt and memory rewrites remain unchanged. Custom
  delegation, model-selection, and Guardian rejection wording moves to the
  shared prompt resolver. Explicit configuration retains priority over catalogs.
- Explicit, balanced, and proactive delegation remain independent of reasoning
  effort. Session concurrency changes update the refactored runtime limiter.
  Ordinary messages and child completion still wake idle recipients.
- Bundle storage, queries, retained truncation, and bounded parallel-call
  guidance remain. Nonempty catalog Code Mode descriptions receive the custom
  runtime-helper supplement if they omit bundle documentation.
- Image-based equation typesetting remains local and is not replaced by
  upstream's Unicode renderer. Unicode is the fallback while pictures are
  unavailable. Raw rendering preferences apply to both; image revisions and
  rendering preferences invalidate transcript caches. Streaming and completed
  output use the same fallback.
- Dictation retains account-backed streaming with no personal-key or batch
  fallback. Its connection broker follows selected-workspace routing before
  sending credentials. Tests use fake credentials and a local HTTPS mock.
  Explicitly remapped voice shortcuts take precedence over idle F8 dictation.
- Up-arrow recall retains pending Enter/Tab messages and accommodates upstream's
  image-submission and startup-recovery queues. Conditional turn interruption is
  complementary, not a replacement for recalling one pending message.
- Directory watches, persistent monitors, and monitor database isolation remain.
  Upstream changes prompt editing from fork to in-place revert; monitors pause
  after a successful revert, as they did during the prior fork-based workflow.
- Reserve opt-out remains at the usage-request boundary, including filtering
  unsolicited fallback offers. No local config or running daemon was changed.

## Audit caveats

Model-catalog overrides can intentionally replace bundled wording. The custom
base-prompt file is separate from that mechanism. New model families do not
automatically inherit bespoke catalog text.

The prompt ledger records a P0 manual size-review finding: configurable Guardian
policy additions have no per-message size cap. No such override was enabled
locally. The merge does not silently truncate security policy text.

Fullscreen behavior and real Kitty image placement still warrant a manual
terminal check; snapshot and protocol tests cannot prove compositor behavior.
No real account audio, live model request, or work-workspace verification is
part of the test run.

## Post-merge audit fixes

  the remote-server restriction. F8 remains the default dictation key; voice
  moves to F9 to avoid the upstream shortcut collision. Cover both keyboard
  gates without live audio.

  a thread switch cannot silently turn raw math back into Unicode.
- Save paused monitor state after a successful in-place prompt revert. A
  restored thread keeps the monitor paused.

  independent work alongside useful local work. Catalog overrides remain
  authoritative.
